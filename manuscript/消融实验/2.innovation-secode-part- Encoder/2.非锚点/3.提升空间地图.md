## 4. 结论（已按 decision-reviewer 意见修正）

1. **补 RNA 的空间小但不为零**：T1 上 LGG +0.009±0.003（配对可检出）、其余 ≤ 0.006。根本原因是当前网络下 RNA 本身带来的信息就少（LGG 0.030，其余 ≤ 0.008）。沿这条路很难做出像样的性能故事；此结论限于当前网络与特征。
2. **报告缺失的损失最大，现有填补都追不回**（T1：LGG 0.094、UCEC 0.047、BRCA 0.036）。报告缺失在临床上是否现实属领域判断，**交用户裁决**，不直接排除（论文网格本身含 text_100）。
3. **最能动的杠杆是文本表示**：在最贴近临床的 none 场景下，LGG、UCEC 换表示能差 0.05–0.08，超出纯噪声期望 2 倍以上；BRCA、BLCA、LUAD 边缘。没有一种表示在五癌都最好。
4. **作者文本特征的疑点（待查，不下结论）**：作者特征在 LGG / BRCA 明显领先，在 UCEC / LUAD / BLCA 反而落后。可能的解释并列：编码器更强；文本来源不同；在 TCGA 生存标签上微调过。疑点：作者特征在 LGG / BRCA 的 seed SD 异常小（0.010 / 0.007，我们各臂 0.015–0.042）。若第三种成立且其训练集覆盖本项目 test 病人，则存在标签泄漏，受影响的是**所有用了作者特征的结果**（含论文基线与 Table 1）。

运行环境：`/Users/wuhao/miniconda3/envs/protomasksurv-exp1/bin/python`。第 3.2 节的可信度表由主控另行计算（公式见表上方）。

```python
"""提升空间地图（零训练、只读）：从现有逐 seed 结果算每个癌种、每个环节还剩多少空间。

口径（与对话中先行约定一致，全部按 seed 配对后报 均值 ± 标准差）：
  模态价值  value_g  = none(m0real) − g(m0real)            遮掉该模态、不做补偿时损失多少
  补偿空间  space_g  = none(最优策略) − g(最优填补策略)     任何补偿方法能追回的上限（相对当前这批网络）
            「最优」按五 seed 均值选定，再逐 seed 配对求差，避免逐 seed 挑最大值
  噪声参照  noise    = none(strategy0) 五 seed 的标准差
  文本表征空间：none 场景 strategy0 下，7 种文本表示的五 seed 均值极差
"""
import json
import re
import numpy as np

ROOT = "/Users/wuhao/Desktop/TriModalSurv"
FILES = {
    "T1": f"{ROOT}/experiments/I01_patient_retrieval/knowledge/data-analysis-from-grok/4.progress/runs/test/complete.json",
    "B1": f"{ROOT}/experiments/BioClinical ModernBERT/results/i05-bcmbert200-20260924d/evidence/formal_eval/runs/test/complete.json",
    "B2": f"{ROOT}/experiments/BioClinical ModernBERT/results/i05-a0-20260924/evidence/formal_eval/runs/test/complete.json",
}
A1_MD = f"{ROOT}/manuscript/消融实验/2.innovation-secode-part- Encoder/prototype_learning/6.LLM浓缩-A1/6.LLM浓缩-A1-result-癌症为单位.md"
C = ["LGG", "BRCA", "UCEC", "LUAD", "BLCA"]
SEEDS = [123, 132, 213, 231, 321]
STRATS = ["m0real", "m1", "strategy0"]
GRIDS = ["rna_100", "text_100", "both_100"]


def load(f):
    v = {}
    for r in json.load(open(f))["rows"]:
        v[(r["cancer"], int(r["seed"]), r["grid"], r["protocol"])] = r["c_index_b"]
    return v


def vec(v, c, g, s):
    return np.array([v[(c, sd, g, s)] for sd in SEEDS])


def fmt(x):
    return f"{x.mean():+.3f}±{x.std(ddof=1):.3f}"


def part_a():
    print("## A. 模态价值与补偿空间（均值±SD，5 seed 配对）\n")
    for arm, f in FILES.items():
        v = load(f)
        print(f"### {arm}\n")
        print("| 癌种 | none(Proto) | 噪声SD | RNA价值 | RNA补偿空间 | 报告价值 | 报告补偿空间 | 双缺价值 | 双缺补偿空间 |")
        print("|---|---|---|---|---|---|---|---|---|")
        for c in C:
            none_p = vec(v, c, "none", "strategy0")
            ref = max(STRATS, key=lambda s: vec(v, c, "none", s).mean())
            cells = []
            for g in GRIDS:
                val = vec(v, c, "none", "m0real") - vec(v, c, g, "m0real")
                best = max(STRATS, key=lambda s: vec(v, c, g, s).mean())
                sp = vec(v, c, "none", ref) - vec(v, c, g, best)
                cells += [fmt(val), f"{fmt(sp)}（{best}）"]
            print(f"| {c} | {none_p.mean():.3f} | {none_p.std(ddof=1):.3f} | " + " | ".join(cells) + " |")
        print()
    # 自检：T1 strategy0 none 均值应等于论文 Table 1 None/Proto（LGG 0.797723）
    v = load(FILES["T1"])
    print("自检 T1 LGG none strategy0 均值:", round(vec(v, "LGG", "none", "strategy0").mean(), 6), "（论文 0.797723）\n")


def part_b():
    text = open(A1_MD, encoding="utf-8").read()
    arms = ["作者特征", "B1 前200", "B2 全文", "A1-S", "A1-Z", "A2-S", "A2-Z"]
    print("## B. 文本表征空间（none，strategy0，五 seed 均值）\n")
    print("| 癌种 | " + " | ".join(arms) + " | 极差 | 作者 − 我们最好 |")
    print("|---|" + "---|" * (len(arms) + 2))
    for c in C:
        sec = re.search(rf"### {c}[^\n]*\n(.*?)(?=\n### |\n## |\Z)", text, re.S).group(1)
        vals = {a: [] for a in arms}
        for line in sec.splitlines():
            p = [x.strip().strip("*") for x in line.split("|")]
            if len(p) > 10 and p[1].isdigit() and p[2] == "None":
                for a, x in zip(arms, p[3:10]):
                    vals[a].append(float(x))
        m = {a: np.mean(vals[a]) for a in arms}
        ours = max((a for a in arms if a != "作者特征"), key=lambda a: m[a])
        print(f"| {c} | " + " | ".join(f"{m[a]:.3f}" for a in arms)
              + f" | {max(m.values()) - min(m.values()):.3f} | {m['作者特征'] - m[ours]:+.3f}（{ours}） |")


if __name__ == "__main__":
    part_a()
    part_b()
```
