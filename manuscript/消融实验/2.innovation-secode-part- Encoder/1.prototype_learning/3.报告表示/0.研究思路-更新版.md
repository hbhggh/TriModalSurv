# 研究思路与已有核验成果｜更新版

**目标：在多模态癌症生存预测中，先找到真实的小缺口，再用成熟方法的针对性改造形成方法论文。具体缺口、模态组合、骨架和方法均未锁定。**

### ① 当前研究范围

保留两个并列的大范围：

- **整模态／整分支缺失**：整份文本、图片或整个组学分支不可用。
- **模态内部部分信息缺失**：模态仍存在，但部分信息不可用。

新增多组学后，还需单独区分：**组学分支存在，但其中某一类组学缺失**。这与某类组学内部的个别特征缺失不同。

以上都是搜索范围，**不能直接当作已成立的新问题**。

### ② 文本优先，允许三种组合

| 候选组合 | 结构与边界 |
|---|---|
| **文本＋WSI** | 文本与病理图像两个输入分支。 |
| **文本＋RNA** | 文本与转录组两个输入分支。 |
| **文本＋多组学** | 文本与多组学联合表征两个顶层分支；组学内部仍包含不同数据类型。 |

“文本优先”表示优先围绕文本相关不足寻找缺口，**不预设文本必须主导模型**。

“文本提升空间最大”仍是待验证判断。具体采用哪些组学，以及文本仅限病理报告还是包括其他临床记录，均未确定。

### ③ 骨架、方法与实验原则

- **骨架**：优先使用性能可靠、代码和资源可复用的生存预测强基线；原论文可以没有研究缺失问题。
- **方法**：先明确失败条件，再决定改造内容。不提前锁定原型、提示、扩散等模块。
- **资源复用**：尽量沿用公开数据、划分、特征和实验流程，减少重复劳动。
- **结果引用**：患者、划分、输入模态、特征、缺失设置、终点及指标等条件充分对齐时，可以引用并标明“原文报告”。
- **必要验证**：完整输入成绩不能代替缺失成绩；自己的改进及关键对照仍需实际验证。

### ④ 已有核验成果

| 工作与证据 | 对选题的影响 |
|---|---|
| **[MUST，CVPR 2026](https://arxiv.org/html/2603.26071v1)**：共享／模态特有表征分解＋条件潜在扩散。已读方法章节。 | 此前“选择性原型学习”的理解不准确，不能基于该理解设计迁移。 |
| **[SELECTOR，2024 年预印本](https://arxiv.org/html/2403.09290v1)**：明确处理生存预测中的模态内特征缺失。已读摘要及 §3.4。 | “生存分析＋部分信息缺失”整体上不是新问题，必须继续细分。 |
| **[LNLN，NeurIPS 2024](https://arxiv.org/html/2409.20012v2)**：研究模态内部随机信息删除，包括文本词缺失。已读相关方法。 | 随机删词或遮挡特征本身不能构成新颖性。 |
| **[EMMS，MICCAI 2026](https://papers.miccai.org/miccai-2026/0355-Paper6476.html)**：已研究缺失模态下的不确定性、可靠性融合和校准。已读摘要及部分方法。 | 不能笼统声称现有方法都忽略这些因素。 |
| **[MOSAIC，2026 年预印本](https://arxiv.org/html/2607.01821v1)**：研究不同缺失模式下的预测规则与模式间校准。已读引言及理论定义。 | “区分缺失模式进行校准”已有相关研究，不能直接当成空白。 |

**骨架资源：**[Song 的工作](https://github.com/StevenSong/multimodal-cancer-modeling)有文本参与的 Cox／后期融合流程；[PS3](https://github.com/manahilr/PS3)有三模态 Transformer 实现，但双模态适配尚未核实；[Rasa](https://github.com/zhengwang9/Rasa)本次查看的公开仓库只有说明等文件。**尚未确认能直接复用的最终骨架；多组学＋文本方向尚未完成专门查重。**

### ⑤ 保留的候选线索——不是已确认的创新点

| 线索 | 还缺什么证据 |
|---|---|
| 报告存在，但预后相关事实或段落缺失 | 是否造成稳定损失；与随机遮挡有何实质区别；已有方法是否仍不足。 |
| 另一模态缺失后，文本不完整造成额外损害 | 是否存在额外影响；去噪、可靠性融合及补全方法能否解决。 |
| **多组学分支内部不完整时，与文本融合出现具体失败** | 缺哪类组学、怎样缺、损失在哪里，以及最相关方法合理适配后的不足，均待核验。 |
| 缺失鲁棒训练损害完整输入能力 | 此前本地有线索，但原因与现有解决方案的适用性尚未明确。 |
| 不同缺失状态患者的风险分数不可比 | 需区分排序与概率校准，并检验相关校准方法是否已经足够。 |

此前本地相似度分档**未稳定支持“匹配越差、补偿越有害”**，但不能据此排除所有选择性补偿。本次整理未重新计算本地结果。

### ⑥ 最终判据与当前状态

**缺口三证：真实存在 → 造成重要损失 → 最相关方法及合理适配仍解决不好。**

必须区分：自然缺失与人工遮挡、未测量与测得为零、报告未提及与明确否定。不能通过换任务名称、模态组合或模块名称代替创新论证。
