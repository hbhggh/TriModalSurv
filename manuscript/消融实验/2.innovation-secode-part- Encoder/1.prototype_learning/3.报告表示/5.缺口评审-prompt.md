# 任务：评审多模态生存分析方法论文的「研究缺口」候选

你是计算病理与多模态学习方向的资深审稿人。请对下面 10 个缺口候选做独立评审，选出值得做的方向。不要迎合我的措辞；某个候选不成立，就直接判否并说明理由。

## 一、背景

- 我在写一篇方法论文，任务是 TCGA 癌症病人的多模态生存预测（时间-事件，指标为 C-index）。
- 模态：病理全切片 WSI + 病理报告文本 + 组学（RNA，可另加蛋白）。
- 目标期刊：SCI 中科院三区。按三区方法论文的门槛判断，不按顶会标准。
- 我找缺口时一直犯一个错：先看自己模型的内部数字，再给它找意义，结果讲不成故事。这次要反过来，**从数据和真实使用场景出发**。问题必须客观、听起来有价值，不能是我们为了发论文捏造出来的边际问题。

### 2.4 领域惯例

- SurMoE 表 1 里的 14 个多模态方法都只用 WSI + 基因组，没有一个用文本。
- 其中 M3IF、GPDBN、HFBSurv 三行的数值与 CMTA 论文里的复现值逐项一致，疑似沿用 CMTA 的复现结果，与原论文设置不同。
- 这些方法的代码会读入临床列，但都把前 12 列元数据剔除，临床变量从未进入模型。
- MCAT 五癌（BLCA、BRCA、GBMLGG、LUAD、UCEC）是沿用下来的惯例，MCAT 原文称之为 “the five largest”；但按配对病人数，BLCA 只排第 7（LUSC、HNSC 都比它多）。
- 缺失模态论文的表 1 不把自己的方法放进单模态行；只有在声称缺失鲁棒性时，才另做「测试时去模态」的表（如 LD-CVAE 表 2）。
- 带文本的生存分析工作在 2024–2025 年才陆续出现：CALM、SurvPGC、TriBind-Mamba、PS3（ICCV 2025）、Song 2025。

### 2.5 我们已有的现象

以下来自之前的骨架 NPJ-C 和旧数据（TCGA 五癌、固定随机划分），不是新数据路线上的结果：
- 只凭采集中心预测生存，C-index 在 LGG 就有 0.720、BRCA 0.663、UCEC 0.626。
- 文本对 C-index 的贡献低于 WSI。
- 两轮更换文本编码器都是负结果。
- 小效应（0.01–0.03）在只用 test、几个癌种合并的条件下测不出来（CI 半宽约 0.035）。

### 2.6 病理报告的性质

- 报告是病理医生对同一张切片的总结，含分期、分级、组织学类型这些强预后变量。
- 不同医院的模板差异大。
- 自由文本比图像和组学更难脱敏。

## 三、触发场景与候选

我需要决定缺口落在哪一层：
- **第一层**：缺口就是「模态缺失」本身；
- **第二层**：在模态缺失背景下的一个子问题；
- **第三层**：与模态缺失平行的问题（模态都在场，但有别的问题）。

每条候选按「场景 → 看得见的问题 → 一句话原因 → 拟用的成熟方法」写。

**第一层**
- **M0 整模态缺失补偿**：部署时病人缺基因检测 → 预测掉点 → 融合依赖模态之间的相关性 → 生成式补全或特征补偿。

**第二层**
- **S1 报告因隐私出不了医院**：跨机构合作或外部验证时，图像和组学能脱敏共享，自由文本很难脱敏，所以训练时有报告、部署时没有 → 掉点 → 模型依赖文本里的强信号 → 特权信息学习（LUPI）或知识蒸馏。
- **S2 缺失不是随机的（MNAR）**：真实队列里谁缺哪种数据，和中心、病情有关 → 部署时的缺失分布和训练时对不上 → 现有方法训练时随机遮挡，默认缺失是随机的 → 把缺失模式当成输入、按缺失模式分层、逆概率加权。
- **S3 补出来的特征过度自信**：生成模型从 WSI 补出基因或文本 → 补出来的特征被当成真的用，没有不确定性信号 → 只优化 C-index → 不确定性加权、证据学习、保形预测。
- **S4 多组学整体与文本同时缺失**：基层医院既没测序，报告又很简略 → 两个都缺时，补偿找不到锚点 → 组合缺失建模。
- **R1 只研究真实缺失的病人（新增，请重点评审）**：
  - **观察**：现有缺失模态的生存分析论文，往往先从真实数据集里淘汰模态不全的病人，只留模态齐全的病人；再在推理阶段用掩码把整个模态遮掉，模拟缺失。这样研究的是「人造缺失」，不是真实缺失。
  - **设想**：直接从真实数据集里天然缺失模态的病人入手；更激进的版本是只研究这些真实缺失的病人。
  - **好处**：研究场景完全基于真实情况，有实际意义。
  - **争议 1：病人数急剧减少，模型可能训练不充分。** 我想到的一个机会是：别人的方法在少量数据上也会变差，如果我们的方法在少量真实缺失病人上训练仍能取得较好成绩，就能拉开差距。请评审这个想法是否成立、是否公平，会不会被审稿人认为是刻意削弱基线。
  - **争议 2：本质上是长尾问题。** 病人太少，统计误差会很大，结论可能不可靠。
  - **已知数据**：见 2.2。在 TCGA 五癌里，有切片但缺 RNA 的约 49 人，缺报告文件的几乎为 0。全部 33 个项目里，只有 GBM 有像样规模的真实缺 RNA（166 人），缺文本的在任何项目里都是 0。
  - **请额外回答**：
    1. 按 2.2 的规模，R1 在 TCGA 上是否可行？下面三个方向哪个更好：
       - A：主实验仍用人造缺失，把少量真实缺失病人单独报告；
       - B：加入 GBM，研究按平台、按年代缺 RNA（与 S2 结合）；
       - C：换用天然缺失更多的真实队列（如 HANCOCK）。
    2. 与 2.3 里的两篇先行工作（Briefings in Bioinformatics 2026、Ruffini 2026）相比，R1 还剩什么新颖性？
    3. 有没有折中方案？比如训练时用全部病人（完整的和不完整的都用），评测时把真实缺失的病人单独报告；或者比较「人造缺失」和「真实缺失」两种评测得出的结论差多少。

**第三层**
- **P1 换医院，报告模板一变就掉点**：新医院的报告格式和措辞不同 → 文本分支学到的是中心模板，不是病情 → 领域泛化、对抗去掉中心信息、按中心分层验证。
- **P2 文本抢走了图像的作用（模态不平衡）**：报告里有分期、分级这些「答案」，模型偷懒只看文本 → 报告简略的病人预测差，WSI 分支学不到东西 → 梯度调制类不平衡学习（如 OGM-GE）。
- **P3 增益其实是分期带来的**：医生本来就有分期 → 多模态提升可能全来自分期，临床上没有增量价值 → 在临床 Cox 基础上做残差学习，去掉分期后重新评估。
- **P4 报告与切片冗余**：报告是对切片的总结，简单拼接会重复计数 → 过拟合，而且说不清文本有什么新信息 → 解耦共享信息和特有信息（类似 CMTA、PIBD 在基因与病理之间的做法）。

## 四、强约束（违反任一条即判否）

1. 期刊只投 SCI 中科院三区，判据和实验规模都按三区校准。
2. 多模态生存分析（时间-事件），必须有图像模态。
3. 方法论文：创新落在编码器、Transformer、特征融合或算法结构上，用成熟方法针对原因做改造；不做纯分析类文章。
4. 底线：公平对比（同特征、同划分、同评测口径；不能为了让自己赢而刻意削弱基线）、防 test 泄漏（不在评估集上选模型或选癌种）、如实报告。
5. 若主张涉及文本缺失或「文本是噪声大的辅助模态」，结果部分必须有三类实验：
   1. 缺失场景对比表：训练用完整数据，测试时去模态，我们的方法必须在表内；
   2. 单模态与双模态参考线；
   3. 模态消融。

## 五、约束清单（评审时逐条对照）

- **判据 1：故事性强**。能写成「在【真实场景】下，现有方法【出现看得见的问题】，因为【一句话原因】；我们用【成熟方法】针对原因改造」，并且属于「别人没处理过」或「别人处理过但不够好」。
- **判据 1 的四个检验问题**（每个候选逐条回答「是 / 否 / 部分」；过三条以上，才算「从数据出发、听起来有价值」）：
  1. **不提我们的模型，能不能把问题讲清楚？** 只用临床流程、法规或数据描述就能说明白，算通过。
  2. **训练任何模型之前，数据里能不能直接看到这个现象？** 用描述性统计就能看到（缺失比例、缺失和中心的相关性、各中心的生存差异等），算通过。
  3. **医生或审稿人听完会不会点头说「这确实会发生」？** 最好有法规、指南或已发表的数据报告作外部依据。
  4. **它发生得多不多，损失大不大？** 只影响很少病人、或者只差 0.005 的，属于边际问题，不通过。
- **判据 2：证据三条**：
  - ① **真实存在**：有文献、理论或诊断实验支持，排除实现错误和偶然波动；
  - ② **重要**：说得清造成什么损失，解决后改善什么；
  - ③ **现有方法解决不了**：在明确条件下，最相关的现有方法及其合理适配仍留下具体不足。
- **可行性**：只用 2.1 的数据路线，能否构造出这个场景？有没有能在正式训练前、低成本看到现象的诊断实验？
- **统计功效**：参照 2.3，同一方法跨论文差约 0.02，缺模态掉点约 0.035，方法之间的领先约 0.01–0.02。效应量要大到在五癌、5 折交叉验证下测得出来；小于 0.03 的 C-index 提升视为高风险。小样本候选（如 R1）请给出大致的置信区间宽度估计。
- **新颖性**：请列出你知道的最相关工作。**每条必须给可核验的出处（作者、年份、会议或期刊，最好有 arXiv 号或 DOI）。拿不准的明确标「不确定」，不要编造文献。**
