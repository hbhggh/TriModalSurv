## 阅读与编辑

初稿从 [main.tex](bmc_initial_draft/main.tex) 开始；需要补充的内容见 [FILL_ME.md](bmc_initial_draft/FILL_ME.md)，文献条目见 [references.bib](bmc_initial_draft/references.bib)。PDF 是编译产物，正文修改应回到源文件。

结果数字与论文声称应指向 [experiments/](../experiments/README.md) 中的原始结果和分析，不能用论文草稿替代实验记录。方法学习笔记放所属实验 `knowledge/`，历史稿件原件通过 [archive/](../archive/README.md) 追溯。
