## 怎么读

每个文件自上而下是：

1. **实验地图**：左边是对比基准，中间是类别，右边是具体实验
2. **总览表**：一行一个实验，一眼看完
3. **类别节**：`## 类 N`，每类下面挂实验卡片
4. **附：放弃项**：没跑出结果的尝试

归类按「改了哪一部分」划分。一类就是论文里的一组对比。

## 实验卡片模板

表格不重新整理：当时实验跑完输出的表格是什么样，就原样贴进来。复制下面这段，填进对应类别下面。

```markdown
### <实验名>（<ID / run_id>）

来源：结果文件链接（脚本生成）· run_id · commit / tag · 溯源状态

**当时的输出（原样）**

<实验跑完时汇报的结论与表格，原样粘贴>

**结果文件原表**（第 x–y 行原样复制）

<从结果文件原样复制的表格；原文的 ## 标题降为 ####，其余一字不改>
```

## 追加一个新实验

1. 判断它改的是哪一部分，放进对应的 `## 类 N`；没有合适的类别就新开一类
2. 复制卡片模板，原样贴入当时输出的表格
3. 在总览表加一行
4. 在实验地图加一个节点

## 数字规则

- 表格原样复制：来自实验跑完时的汇报，或脚本生成的结果文件（文件第 1 行有 `GENERATED` 字样），注明文件和行号。
- 不自己整理、挑行、重算或改写表格。
- 链接只写文件，行号写在文字里。在链接后加 `:行号`，查看器会打不开。
- 不写本机绝对路径（带用户名的家目录路径），一律用相对链接。
