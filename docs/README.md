# docs：项目文档与知识导航

保存跨实验的工程规则、方法构想、工作流说明与重构证据。某个已实现创新点的方法解释和结果分析放回所属实验。

## 内容索引

| 路径 | 用途 |
|---|---|
| [project-structure.md](project-structure.md) | 整个项目的目录结构与分类边界 |
| [engineering/](engineering/) | 工程纪律与唯一[坑台账](engineering/pitfalls.md) |
| [metrics/](metrics/) | 指标、风险计算口径等说明 |
| [research-ideas/](research-ideas/) | 尚未落地的研究构想 |
| [workflow/](workflow/) | 编辑器、文档编辑与知识整理方法 |
| [assets/](assets/) | 文档引用的图片、图形等附件 |
| [refactor/](refactor/) | 重构清单、路径映射、审核与验收证据 |
| [templates/](templates/) | 可复用的[科研初始化规范](templates/experiment-oriented-ml-template.md) |

## 放置规则

已有知识原文与删除线保留，新增说明通过索引关联。创新点知识放 `experiments/<ID>/knowledge/`，实验结果与分析放其 `results/`，论文正文放 `manuscript/`。项目最新状态统一记在根 [STATUS.md](../STATUS.md)。
