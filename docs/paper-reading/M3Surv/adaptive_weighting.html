M³Surv 自适应切片权重

w_ff、w_ffpe 怎么算出来，P_s 怎么由它们加权得到 · 对应论文式 5 与图 2 的 Adaptive Weighting

w_ff、w_ffpe 是这位病人两张切片各自的一个标量，直接乘在未池化的 P_ff ∈ ℝ^(N_ff×d)、P_ffpe ∈ ℝ^(N_ffpe×d) 上，形状不变。两块行数不同，不能逐元素相加，所以沿 token 维拼接成 (N_ff + N_ffpe) × d，再经片间超图卷积得到 P_s。

计算流水线 · 示意数据（d 取 8，FF 画 8 行，FFPE 画 10 行代表 4096 行）

① 每张切片打一个分

每个 patch 向量乘 W_ff 得到一个分数，再对全部 patch 求平均，得到这张切片的总分 s_ff。

(N_ff×d)·(d×1) = N_ff×1 → 求平均 → 1×1

② 两个分数做 softmax

两张切片的总分一起做 softmax，得到两个加起来等于 1 的权重。分数高的切片权重大。

两个标量 → 两个标量，w_ff + w_ffpe = 1

w_ff 是这位病人 FF 切片的一个数，切片里所有 patch 共用它；左边那列逐 patch 分数只是算出 w 的中间量。换一位病人，w 会变。

③ 门控后拼接，再做超图卷积

权重乘在整块未池化矩阵上；两块行数不同，沿 token 维拼接，再在式 4 的片间超边上做 L 层超图卷积。

N_ff×d、N_ffpe×d → 拼接 (N_ff+N_ffpe)×d → 超图卷积后形状不变

和论文、作者代码的出入

为什么拼接而不相加：P_ff 有约 300–500 行，P_ffpe 有 4096 行，行数不同的矩阵不能逐元素相加；不池化又要合并，只能沿 token 维拼接。若写成 w_ff·P_ff + w_ffpe·P_ffpe，就必须先池化成 1×d，P_s 只剩 1 行，式 6 的注意力会退化（softmax 只有一个元素，恒为 1）。
与论文、代码的对应：拼接后的形状 (N_ff + N_ffpe) × d 与作者代码一致（model_M3Surv.py 第 194 行拼接，第 207、211–214 行在片间超图上做 3 层卷积）。论文只说权重「整合进超图卷积」，没写乘在哪一步；本页把它乘在卷积前的输入上，这个位置是推断。
打分怎么汇聚成一个数：式 5 没写 W_ff P_ff 的 N 个分数如何变成一个标量；本页取均值，和作者代码的 torch.mean 一致。
代码里的权重：作者代码先取均值，再过 sigmoid，加一个 log 修正项，最后 softmax；算出的 weights 之后没有被使用（model_M3Surv.py 第 183–193 行）。

图中矩阵、W 与数值都是固定随机种子生成的示意数据，用来说明维度怎么变化，不是论文的真实数值。点「换一位病人」会换一组数据，权重随之变化。
