# Step 1 — Decompose the Novelty
- 时间：2026-11-11
- 对象：I08 TriModalSurv（M6-a = A1 + B6-LOO + C1），口径来源 handoff-论文生成.md §1.1–1.3

## Research problem
多模态（WSI + RNA + 病理报告文本）癌症生存预测，测试患者缺失部分模态。静态填零/填均值在线性风险头下只差常数，缺失位无患者间差异（Prop. 1）；全维（256 维）恢复参数多（788,736）、对正则敏感，默认超参下负迁移。

## 四轴
- **Problem framing**：冻结的三模态生存骨架（I07），推理期测试患者任意缺 1–2 个模态（6 种缺失模式），目标是维持风险排序（C-index）；完整输入恒等直通；TCGA 5 癌 5 折。
- **Core mechanism**：A1 每模态 Cayley 正交基 U_m (256×32) 把缺失模态拆成共享坐标 + 正交补（正交补截断不恢复）；B1 按缺失模式的线性映射从可见模态预测共享坐标；**B6-LOO**：用岭回归 Hat 矩阵对角元做留一去偏的 B1 训练残差池，按可见模态平均余弦取 Top-K 相似训练患者，加权残差修正 B1 预测，IQR 自适应密度门控（离群则回退 B1）；C1 训练期正交重构锚定 + 跨模态共享方向余弦对齐 + 停梯度恢复一致性。
- **Key insight**：只恢复"可从其他模态预测"的低秩共享部分，避免把模态特异噪声当恢复目标；线性趋势之外的患者级个体偏差由相似患者的留一预测残差补上（避免训练残差过拟合偏小）。
- **Application domain**：计算病理 / 多组学癌症生存分析（TCGA BLCA/BRCA/LUAD/LGG/UCEC），推理期缺失模态鲁棒性。

主故事轴：B6-LOO（用户判定 A1、C1 为最简单做法）。
