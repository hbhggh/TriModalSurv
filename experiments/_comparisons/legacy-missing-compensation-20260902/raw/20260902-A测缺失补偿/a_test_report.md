**结论 2b（归因；只作方向判定，不做份额分解——两分量 E0d−E0 与 E1−E0d 共享 E0d 且逐 seed 负相关，配对Δ中位不可相加，分量和与实际 E1−E0 在关键 3 格相差 0.011~0.018、全 20 格 0.000~0.018；`r4_numbers.txt` 十六）**：
1. **dropout 协议的效应按癌种分化**：20 个癌种×格点中 16 个 |Δ|<0.02。**UCEC 是系统性例外**——4 格点全部正向、其中 3 格超出噪声带（none +0.026、rna_100 +0.021、text_100 +0.038；both_100 +0.011），说明 modality dropout 对 UCEC 有独立于召回的收益；**LGG 缺文本为反向例外 −0.050（1:4；剔 s213 后 0:4，−0.056）**，dropout 训练让 LGG 更依赖被遮的文本。其余三癌（BLCA/BRCA/LUAD）12 格点全部在带内（max |Δ|=0.0082）。
2. **UCEC 完整模态**：协议 +0.026（3:2，超带）与召回 +0.018（3:2，带内）在 5 seed 中 4 个此消彼长（Pearson r = −0.88；s321 例外为两项同正 +0.026/+0.018），**份额不可识别**；可断言的是 dropout 协议本身在 UCEC 已有独立正向，E1 的完整模态收益在 E0d 上已基本出现（+0.026 vs 总 +0.028）。
3. **全缺（both_100）的收益不能由 dropout 协议解释**：E0d vs E0 在 LGG/UCEC 全缺仅 3:2（+0.012）/ 4:1（+0.011），**均在噪声带内**；而 E1 vs E0d 为 4:1（+0.060）/ 5:0（+0.042），**超出噪声带**；LGG 剔 s213 后协议归零（+0.0005）而召回 +0.062。此处"召回"的参照是**不填充**（E0d 在全缺时只剩 WSI），不是"任何填充"。
4. **BLCA/BRCA 的负向不来自协议**：E0d≈E0（|Δ|≤0.0082），而 E1 vs E0d 四格点一致为负（BRCA 缺文本 −0.073；BLCA 剔崩坏 seed 后仍 0:4）——负向由"召回 + 一致性 loss"引入（二者未分离）。**机理边界**：BLCA 的"遮 RNA 反升"（配对中位 +0.004，4:1，噪声带内）与该结论方向一致；但 **BRCA 遮任一模态均掉分（0:5，−0.010 / −0.039），"RNA/文本是干扰"对 BRCA 不成立**；且"反升"幅度最大的 LUAD（遮文本 +0.017，4:1，带内）反而受益于召回。**因此"遮掉反升 ⇒ 召回有害"不是可推广规则**，BLCA/BRCA 的负向机理尚未确定。
5. LUAD：召回四格点方向一致偏正（4:1/4:1/3:2/4:1），幅度 +0.006~+0.016 在噪声带内，只作方向提示。
**边界**：E1 vs E0d 仍含一致性 loss（λ=0.1）这一混淆，未单独消融；both_100 下 E0/E0d 是"不填充"而非作者的常量 token，因此本节的比较是"召回 vs 不填充"，与 gate 版附录中"填充 vs 常量 token"不是同一问题；**"学习式召回 vs 任何填充"未验证**（第四节）。

## 四、机理证据（`probe/*.jsonl`、`notes.md`、`r4_numbers.txt` 十一～十三）
- gate 探针（BLCA s123）：完整模态 gate 权重 img/text/rna = 0.772/0.203/**0.025**；RNA token 范数 8.2 vs img 0.26；置零后常量 token 拿 17–31% 权重；修对 mask 后权重归零但 c-index 最大变化 0.0071 → gate 对缺失近乎无作用（不证明其有害）。
- **遮掉某模态反升**（E0，配对Δ中位 grid−none）：BLCA 遮 RNA +0.004（4:1）、LUAD 遮文本 +0.017（4:1）——**两者均在噪声带内，仅作方向提示**；BRCA/LGG 遮任一模态均 0:5 掉分；UCEC 遮文本 0:5（−0.060）、遮 RNA 1:4（−0.003，带内）。探针同现象（S5 ckpt BLCA 遮 RNA 0.5985→0.6244）。该现象与 RNA 范数碾压 img 同一机理线，但不构成"召回有害"的可推广解释（二 b 结论 4 机理边界）。
- **跨骨架方向只能在完整模态比较**：gate 版 M2 vs M0-real 与 NPJ-C 版 E1 vs E0 在 none 格点（无缺失、基线口径无差异）3/3 同号（BLCA −0.0245/−0.0248、BRCA −0.0073/−0.0201、UCEC +0.0165/+0.0280）；缺失格点因两骨架的缺失基线不同（常量 token vs 不填充）不构成同一比较——单模态 100% 缺失 6 个比较有 3 个反号（BLCA text +0.0035 vs −0.0158、BRCA rna +0.0229 vs −0.0077、UCEC text −0.0142 vs +0.0556）且无一处两侧同时超出噪声带。**跨骨架可迁移性未获支持亦无法证伪**，故 r3 的"有效性由可恢复信息量决定而非骨架"本报告撤回。

## 六、论文故事（r4 修订）
1. **主贡献：以 attention 融合替换伪门控**——作者 gate 的掩码链路为死代码、权重由 RNA 范数驱动（探针）；替换后 20:4:1 seed 提升、LGG +0.091（配对Δ中位）、UCEC +0.023。措辞："替换后一致更好"，不写"gate 有害"（贡献未分离，待消融）。
2. **CAP-Recall：条件性补偿，收益随癌种而定、随信息缺口增大而增大（UCEC 单调；LGG 仅在全缺反转）**——消融后可以明确：(i) 两模态全缺时召回**相对不填充**的增量（LGG +0.060、UCEC +0.042）**不能由 dropout 协议解释**（E0d 消融，协议项在噪声带内、LGG 剔 s213 后归零）；(ii) UCEC 在所有格点受益，其中完整模态的正向在 E0d（无召回）上已基本出现（+0.026 vs +0.028），召回的增量不可单独识别；(iii) 在召回实测有害的癌种（BLCA/BRCA，机理待定），召回应关闭。**学习式召回相对盲补的优势未验证**（gate 版对照提示 LGG/UCEC 上盲补不劣于召回）；本节已按"相对不填充"的保守口径落地，补 E0m（第七节）可把 (i) 升级为"相对盲补亦有增量"或证伪之。**自然引出选择性/自适应补偿（癌种/样本级可恢复性评分）作为下一篇的问题定义**。
3. 三句话进稿：①原骨架 gate 未按声称工作，缺失时以常量 token 照常融合；②我们以 attention 融合替换伪门控，并用 CAP-Recall 从 WSI 锚与癌种原型召回缺失 token；③替换后 LGG 大幅、UCEC 一致提升；召回在信息缺口最大（两模态全缺）时对 LGG/UCEC **相对不填充**有效，且该收益**不能由 dropout 协议解释**，在 BLCA/BRCA 有害——为选择性补偿提供实证。
