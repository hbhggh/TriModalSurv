# strategy3:多跑种子➕λ刷选

**结论先说：靠扩种子 + 调 λ，BLCA 四场景均值没有「极大可能」翻过 m0；λ 在 rna_100 上进不了赢家集合。4/5 仍然只该打 LUAD。这条路径当「选种子冲胜率」不可行；当「预注册多种子、全报、valid 锁 λ」只提高绝对分的方差估计，不保证相对胜率。**

## 1. 均值博弈：账算不平

BLCA 现 5 seed × 4 场景（已锁组合 λ=1, text 走 m0）：


| 场景     | 组合     | m1           | m0           | 组合−m0       | λ 能不能动                            |
| ---------- | ---------- | -------------- | -------------- | ---------------- | ---------------------------------------- |
| none     | 0.589972 | 0.589972     | 0.589972     | **0**          | 不能。test 全完整，三臂恒等            |
| rna_100  | 0.588168 | 0.589105     | **0.593546** | **−0.005378** | λ 只在 m1↔检索之间                   |
| text_100 | 0.575989 | 0.574913     | **0.575989** | **0**          | 已是 m0；再填只会 ≤ 这条              |
| both_100 | 0.561797 | **0.574774** | 0.574046     | −0.012248     | λ→0 最多摸到 m1，对 m0 约**+0.0007** |

四场景对 m0 的差：

\[
\frac{0 + (-0.005378) + 0 + (-0.012248)}{4} = -0.004406
\]

要总均翻 m0，必须 \(d_{\mathrm{rna}}+d_{\mathrm{text}}+d_{\mathrm{both}}>0\)。

三条硬顶：


| 格       | 现有臂天花板         | 含义                            |
| ---------- | ---------------------- | --------------------------------- |
| none     | 0                    | 没有「显著提升」可挖            |
| text_100 | 0（m0 已是三臂最好） | 重开检索/改 λ 相对 m0 期望 ≤0 |
| both_100 | m1−m0 ≈**+0.0007** | 把 λ 降到 0 只能买到这点       |
| rna_100  | **m1 和检索都输 m0** | λ∈[0,1] 插的是两个输家        |

λ 的定义是 `μ + λ(donor−μ)`，填完 **valid 仍为真**。它到不了 m0（mask 掉）。BLCA rna_100 的赢家恰恰是 m0。所以 **整条 λ 曲线都在这条场景的失败侧**。C-index 对 λ 可以非单调，但没有证据表明中间 λ 能跳出「假 RNA 对 dropout=0 的融合是 OOD」——m1 已经是最温和的假值，仍 −0.0044。

把能挖的都挖尽（rna 仍填、both 用 m1、text 保持 m0）：

\[
(-0.0044)+0+(+0.0007) = -0.0037 \Rightarrow \text{四场景均仍约 }-0.0009\text{ vs m0}
\]

只有 **rna 也改成不补**（这是路由，不是 λ），rna 项才归零；再加 both 的 +0.0007，总均对 m0 大约 **+0.0002**，硬币，不是「显著反超」。

**假设不成立。** 另外三场补不平 rna_100；两场根本补不了，一场只够 0.0007。

## 2. 新种子会不会改分布

同一套 E0（wd=1、无 modality dropout、A 选 B 评、50 epoch）。新 seed 是同一损失面的另一次抽样。

- 现有 5 粒：LUAD、BLCA **粒粒癌种均分都输**。BLCA rna_100 更是 5/5 检索和 m1 都输 m0。
- 213 崩到 0.49，再抽可能再出崩盘，绝对分方差变大，相对符号不一定翻。
- 要 rna_100 检索 > m0，需要融合开始喜欢假 RNA。训练没见过缺失时，这不是「多种子自然发生」，是训练配方问题（你 strategy2 的 dropout）。
- 「加种子时间极低」若指 **重训 E0**：不是推理刀，是新实验。若指 **现 25 个 ckpt 上扫 λ**：valid 已经扫过，全局赢家是 λ=1（被 LGG/BRCA/UCEC 的 both 拉起来的），BLCA 吃的就是这个 λ=1。

LUAD 缺口只有 −0.0017，多种子 **有可能** 擦边翻 1 粒癌种均分；那是 4/5 的运气，不是 BLCA 的 λ 机制。BLCA 对 m0 不靠多种子抹平。

## 3. 策略 3 可不可行 / 怎么才不像挑种子


| 做法                                                          | 可行？        | 学术上                                        |
| --------------------------------------------------------------- | --------------- | ----------------------------------------------- |
| 扩 seed → test 上看癌种胜率 → 留下好看的                    | 能做出 4/5 表 | **不可做。** 选择目标和检验目标都是 test 胜率 |
| 预注册 N 个 seed，**全报** mean±std，胜率当描述统计          | 可做          | 正当。主指标仍应是已赢的 100 格宏平均         |
| 扩库后**按 test 调 λ / 按癌调 λ**                           | 能涨表        | 第二层泄漏                                    |
| 仅 valid 锁 λ（全局或预注册的按癌规则），test 一次，种子全留 | 可做          | 正当，但**不预期** BLCA 过 m0                 |
| 用 λ 冲 5/5                                                  | 与第 1 节矛盾 | 不可作为目标                                  |

规避争议的最低标准（少一条都是挑种子）：

1. 种子名单、N、停训规则 **跑之前写死**，不得因某粒 BLCA 好看而多抽。
2. 主结论用 **全部种子** 的宏平均，不以「胜率 4/5」当选模/选 seed 目标。
3. λ **只在 valid 锁**；test 不得改 λ、不得丢掉输的 seed。
4. 癌种胜率若要报，报 \(k/5\) 的二项区间，并写明 LUAD/BLCA 的场景符号。
5. 1–5 冻结批次与新种子批次 **分表**，禁止混成「组合规则 4/5」。

这样仍 **几乎不会** 得到 BLCA 相对 m0 的稳定反超。它只让你诚实估计「E0 配方下相对差的种子间方差」。
