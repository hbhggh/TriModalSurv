# 规则 5：imputed token downweight

- 保持原 bool attention mask；填入模态仍参与 Transformer attention。
- 仅把最终 pooling 中填值模态的数值权重设为 `w`，本人真实模态为 1、无效模态为 0。
- 不新增 `nn.Module` 参数；固定基线忽略 `w`，`w=1` 应与原 NPJC forward 对齐；输入搬运显式消费 runtime 的 `non_blocking`。

| 函数 | 旧行为 | 新行为 | 影响场景 | 其他四点交互 |
|---|---|---|---|---|
| `build_pool_weights` | 原 NPJC 最终 pooling 对所有 bool-valid 模态等权；无独立数值权重。 | 生成 `[B,3]` 权重：无效=0、本人真实=1、启用⑤的填值=`w`；不修改 bool mask。 | 启用⑤的单点及 combo；固定三基线强制忽略 `w`。 | ①跳过时没有填值可降权；②/④只决定 donor，③只改变填值内容；三者均不改变权重定义。 |
| `weighted_forward` | 原 NPJC 在 Transformer 后对 bool-valid token 等权平均。 | 复用原 projector/backbone/head，仅替换最终 pooling 分子与分母；无新增参数，fp32 inference；输入 `.to(...)` 显式接收 `non_blocking`。 | 所有协议共用；`w=1` 与原 forward 对齐，`w<1` 只影响实际填值模态。 | 接收①–④形成的 inputs 与 imputed 权重；Transformer attention mask 仍由原 bool valid 决定。 |
