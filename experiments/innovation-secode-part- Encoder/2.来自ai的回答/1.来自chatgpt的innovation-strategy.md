结论先行：在当前 NPJ-C + 原型检索方法 的约束下，优先替换 Text encoder，而不是 RNA，更不是 WSI。

这个结论不是因为“BERT 老，所以换新模型几乎一定涨点”。后半句没有证据支持。真正决定优先级的是：接口兼容性、对现有缺失模态补偿逻辑的扰动范围、重提特征成本、对 donor 检索身份的影响、当前底座成熟度，以及外部直接证据。 当前交接材料明确指出，Text 缓存为 [200,768]，RNA 为 [2048,256]，WSI 为 [128,1536]；当前单模态进入 NPJ-C 前都先沿 token 维取均值，再经 Linear → ReLU → Dropout → 256，最终每个模态只形成一个 256 维 token。
 精确配置也确认 hidden_size=256、n_head=4、n_backbone=1、dropout=0.1、pred_dim=4。

因此，一个输出宽度仍为 768 的现代 Text encoder 可以在几乎不改 NPJ-C 骨架的情况下替换离线 Text 特征提取器。ModernBERT-base 系列恰好使用 768 维隐藏状态；BioClinical ModernBERT-base 又针对 biomedical/clinical 文本进行了领域继续预训练，所以接口条件尤其合适。其官方模型卡给出约 150M 参数、最长 8192 token、MIT 权重、transformers>=4.48.0，并说明其训练语料包含约 50.7B biomedical tokens 与 2.8B clinical tokens；ModernBERT-base 的标准 hidden size 为 768。

这两个候选的关键限制是相同的：当前运行所用 Text 基础 encoder、tokenization、padding、原始 pathology report 是否仍可获得，均尚未独立核实。因此现在不能说 k1/k2 已满足全部前提。

尤其要强调三点：

第一，不能直接把新 768 维特征塞进旧 checkpoint，然后把性能变化解释成 encoder 效果。 虽然维度兼容，但旧 Linear(768,256)、Transformer 和 survival head 是在旧特征分布上训练的；语义空间变了，权重兼容不等于统计兼容。严格比较原则上必须让旧 encoder 和新 encoder 在完全相同训练协议下各自训练下游 NPJ-C，再比较五个固定 seed。

第二，WSI 暂时最不应该动。 当前资料记录 WSI 历史来源为 UNI2，而 [1536] 维也与公开 UNI2-h 接口一致，但具体权重版本尚未重新核验。UNI2-h 本身已经是大型 pathology foundation model；更麻烦的是 WSI 不只参与模型输入，还定义原型检索的 patient key。换 WSI 会同时改变患者表征 + donor 邻居身份，严重破坏“只换一个 encoder”的因果可解释性，并要求重新提 tile 特征、重新聚类、重建检索 bank。
 UNI2-h 官方模型卡记录其在超过 200M tiles、超过 350k H&E/IHC slides 上预训练，并输出 1536 维特征。

第三，RNA 有很强的前沿依据，但不是当前最小改动选择。 2026 年的 BulkFormer 已专门面向 bulk RNA-seq，约 150M 参数、约 20k protein-coding genes、581,503 个 bulk RNA-seq profiles，并报告 transcriptome/prognosis 等任务改善；2026 年 Bioinformatics Advances 的研究也把 scFoundation embedding 应用于 25 个 TCGA 癌种生存分析。
 但后一项研究非常值得警惕：foundation-model embedding 单独使用并没有自动超过原始 mRNA 表达；论文中 embedding-only 平均 C-index 约 0.624，而 mRNA+clinical 约 0.681，真正最好的 EGSP 是把 pretrained embedding、原始表达和临床变量组合起来，平均 C-index 0.724。
 这正面否定了“换一个更现代 encoder 大概率必涨”这种过度乐观推断。

本次还实际使用了 Consensus 检索生物信息学/癌症生存文献。命中的直接证据包括 BulkRNABert 的 bulk RNA 癌症预后研究、scFoundation→bulk RNA 生存研究、HGCN 缺失多模态生存研究，以及 PS3 病理报告/WSI/RNA 生存研究。

这里有一个对新 encoder 实验极关键、但很容易被忽略的工程风险：NPJ-C 对 token 维执行的是无 mask 的普通 mean(dim=1)。 因而在尚未恢复当前 Text encoder 的 padding 规则前，不能贸然把新 tokenizer 的 [PAD] hidden states 存成固定 200×768 后直接平均。否则你同时改变了“encoder”与“padding/pooling 语义”。正式实验前必须首先核验旧 Text cache 的 token 数、padding 行是否为零、是否包含特殊 token，以及旧 extractor 是否在保存前做过 mask。

外部文献也支持“Text 是值得研究的信号”，但并不证明某个新 encoder 会必涨。ICCV 2025 的 PS3 在六个 TCGA 数据集上联合 WSI、pathology reports 和 transcriptomic pathway 信息进行 survival prediction，作者报告相对于多种基线取得更好的结果；这是病理报告对同类 TCGA survival 任务有价值的直接证据。
 更值得注意的是，PS3 的公开实现没有简单使用泛化 BERT：它实际用 vinid/plip 的 CLIP text tower 对 pathology reports 分段编码。 但 PS3 同时引入 diagnostic prototypes、histology prototypes、pathway prototypes 和新的 Transformer fusion，因此它不能作为“PLIP encoder 单独带来涨点”的因果证据。

顶会 missing-modality 文献同样值得看，但大部分不能作为本轮 k。CVPR 2025 DisPro 专门解决 incomplete multimodal survival prediction；ICCV 2025 SimMLM 用 Dynamic Mixture of Modality Experts 和额外 ranking loss；CVPR 2025 Knowledge Bridger 做 training-free missing modality completion；ECCV 2024 的 joint-embedding 方法通过 prompt/PEFT 预测缺失模态 embedding。
 这些工作说明 missing modality 仍是很活跃的方向，但它们改变的是缺失补偿、融合、loss 或训练机制，而不是简单替换单一 modality encoder，因此违反本任务 Boundary，不能包装成“低成本 encoder 替换”。

为什么这个顺序是 Text > RNA > WSI：

Text 的最大优势不是“BERT 古老”，而是“接口与实验归因最干净”。 当前 Text projector 的输入宽度固定为 768。 BioClinical ModernBERT-base 以及 Clinical ModernBERT 都保持 base ModernBERT 的 768 hidden width，因此理论上无需改 Linear(768,256) 的输入结构。
 更重要的是，none 场景的 donor identity 主要由 WSI patient key 定义；换 Text 时 donor 是谁不需要因为 Text encoder 而改变，只需要把相同 donor 的 text value 重建到新的 feature space。这比换 WSI 干净得多。该检索边界来自当前交接实现。

RNA 的科研潜力可能比 Text 更高，但当前工程风险也显著更高。 BulkFormer 2026 是专门针对 bulk transcriptome 的 foundation model，而不是把单细胞模型生硬迁移到 bulk；其正式论文记录约 150M 参数、20,010 protein-coding genes、581,503 个 bulk RNA-seq profile，并报告 bulk transcriptome 下游任务收益。
 Consensus 检索同样发现 BulkRNABert 是针对 bulk RNA 和癌症预后的专用方法。
 但本仓库当前 RNA cache 是 [2048,256]，其精确提取器与预处理反而尚未证实。
 一旦切 BulkFormer/scFoundation，gene universe、normalization、tokenization、output dimension、donor RNA values 和癌种 train mean 都很可能需要重建。

而且，2026 年 scFoundation 生存研究给出了一个对本项目非常有价值的反例：它的 pretrained scFoundation embeddings 确实包含预后信息，但 embedding-only 平均 C-index 约 0.624，并没有自动超过原始 mRNA+clinical 的约 0.681；真正显著提高到约 0.724 的是 embedding + gene expression + clinical feature fusion。
 在当前任务“不重做融合、不新加一条 raw RNA 分支”的约束下，这意味着 RNA FM 的优秀论文结果不能原封不动迁移为本项目涨点预期。

WSI 当前最不值得动。 交接材料已经记录历史来源为 UNI2，且缓存宽度 1536。
 UNI2-h 官方模型卡同样是 1536 维 pathology FM，且预训练数据达到超过 200M image tiles/350k slides。
 即使未来存在 TITAN、Virchow、H-Optimus 等更强模型，换 WSI 不仅要重新提海量 tile，还会改变用于 patient retrieval 的 key，因而新结果是：

[ \Delta = \text{WSI representation change} +\text{retrieval-neighbour change} +\text{donor value routing change} +\text{downstream adaptation} ]

而不再是干净的 encoder 单因素效应。

候选策略卡片
k1：BioClinical ModernBERT-base —— 推荐候选

机制与原始来源。 BioClinical ModernBERT 是在 ModernBERT 上进行 biomedical/clinical domain adaptation 的 encoder。其 base 版本约 150M 参数，ModernBERT-base 架构为 22 层、hidden size 768、12 attention heads，支持最长 8192 token；ModernBERT 引入 RoPE、GeGLU、alternating local/global attention 和 padding-efficient 实现。BioClinical 版本继续在约 50.7B biomedical tokens 与约 2.8B clinical tokens 上训练，并覆盖来自多个机构和临床类型的数据；官方模型卡明确列出 pathology/oncology 类临床数据源。权重以 MIT license 公开，官方建议 transformers>=4.48.0。

官方模型卡上的临床/生物医学 benchmark 还显示 BioClinical ModernBERT-base 在其报告的 ChemProt、Phenotype、COS、Social History、DEID 等任务上整体强于原版 ModernBERT-base，并显著强于较早的 Clinical ModernBERT 在部分任务上的结果。
 这属于 NLP 表征能力证据，不是 TCGA survival encoder 的直接效果证据。

与此同时，ICCV 2025 PS3 给出了更靠近当前任务的证据：pathology report 与 WSI、transcriptomics 联合用于 TCGA survival 是有信息价值的。
 因此 k1 的机制链条是：

modern clinical/pathology-aware linguistic representation
→ 更充分编码诊断、分级、组织学、侵袭等报告信息
→ Text patient embedding 更有预后区分度

Boundary。 k1 只允许替换“原始文本 → token embedding”的基础 encoder。第一阶段应保持输出为 [200,768]，不顺手把 context length 从 200 拉到 8192、不改 token fusion、不改 Transformer、不加 attention pooling、不改 retrieval、不加 prompt learner。否则你一次改了两个以上因素。

这也意味着 ModernBERT 的 8192 长上下文优势在第一阶段故意不完全利用。这是正确的实验设计，而不是浪费：你首先需要回答“encoder 本身是否有效”，而不是把 encoder + context length + pooling 一起换掉。

最大的失败模式有四个：当前 Text 其实并不是老 generic BERT；病理报告太短，ModernBERT 的新架构没有发挥空间；survival 信号主要在 RNA/WSI，Text 是冗余信号；或者固定 200-token truncation 丢掉了最重要的后段病理信息。上述任何一种都可能导致五癌中并非 4/5 上升。

公平比较前提。 不能用“新 Text features + 旧 NPJ-C checkpoint”对“旧 Text features + 旧 checkpoint”作为最终结论。最干净的比较是：

[ \text{Old Text encoder} + \operatorname{Train}{same} \quad \text{vs.}\quad \text{BioClinical ModernBERT} + \operatorname{Train}{same} ]

数据 split、五 seed、optimizer、epoch/early stopping、loss、checkpoint selection、NPJ-C、检索规则、λ=1、α=1、w=0.5 全部固定，只让 Text encoder/cache 来源改变。

k2：Clinical ModernBERT —— 替代候选

Clinical ModernBERT 是 UCLA 团队 2025 年发布的 biomedical/clinical long-context encoder，约 137M 参数，基于 ModernBERT，支持 8192 token，训练材料包括约 40M PubMed abstracts、MIMIC-IV clinical notes 和 medical terminology/ontology 信息；作者公开了预训练实现和模型。

它与 k1 的最大价值不是“可能比 k1 更强”，而是提供一个同样低摩擦、但预训练域不同的独立候选：

[ \text{Clinical ModernBERT} \rightarrow 768\text{-d token features} \rightarrow \text{现有 Text projector} ]

其工程适配基本和 k1 相同。

但从目前证据看，k2 应排在 k1 后面，而不是平级。BioClinical ModernBERT 的作者模型卡在多个 biomedical/clinical benchmark 中直接列出了 Clinical ModernBERT，并报告 BioClinical base 整体更强；BioClinical 的训练数据也更广。
 这仍不能证明 k1 在 survival 上更强，只说明在没有 survival 直接比较时，k1 的先验更好。

实验落点与公平复现
首先必须做“资产核验”，然后才谈正式实验。 当前最关键的未知并不是选 k1 还是 k2，而是下面四件事：

必须确认	为什么是 blocker

原始 TCGA pathology report / text 文件是否仍存在	没有原始文本就无法真正替换基础 encoder

是否允许重训 downstream NPJ-C	不重训则旧 projector/head 与新语义空间失配，不能形成强因果比较

当前 dataset 只加载已经生成好的 {patient_id}.pkl Text features，并没有在 dataset 中执行 BERT/其他文本模型推理。 因此真正的修改点应是上游 Text extraction pipeline，而不是 npjc_current.py。

性能和瓶颈方面，Text 路线也最有利。ModernBERT 官方文档指出其设计包含 unpadding、GeGLU、RoPE 和针对长序列的注意力优化；BioClinical 模型卡还建议支持的 GPU 使用 Flash Attention 2。

第一阶段推荐 frozen encoder + 重新训练当前 NPJ-C downstream。 这能把创新点表述为“更强的预训练 Text representation”，同时避免在五癌相对有限患者数上对 150M Text model 做 end-to-end survival fine-tuning。是否进一步 LoRA/最后若干层微调应被视为第二阶段，不与本轮主实验混在一起。

最终决策边界与来源
最终推荐：优先研究 Text，并锁定 k1 = BioClinical ModernBERT-base；k2 = Clinical ModernBERT 作为替代候选。

推荐逻辑可以压缩为：

[ \boxed{ \text{Text} ;\xrightarrow[\text{minimal change}]{200\times768} \text{BioClinical ModernBERT-base} ;\xrightarrow{768\to256} \text{existing NPJ-C} } ]

它之所以优先，不是因为“新模型肯定比 BERT 好”，而是因为当前架构给了它一个异常干净的替换接口：768 维宽度可以保持、WSI retrieval key 不动、RNA 不动、NPJ-C fusion 不动、补偿方法不动。

但推荐成立有三个硬条件：

条件 A：原始 Text 可得。 如果 TCGA pathology report/clinical text 已经无法恢复，只剩现有 .pkl embedding，那么“替换基础 Text encoder”在本轮工程上不可执行。此时优先级应转为 RNA，下一轮首先调查 BulkFormer，而不是强行在旧 Text embedding 上堆一个新的 token MLP。BulkFormer 是当前非常值得认真研究的 bulk-RNA 原生候选。

条件 B：必须查明当前 Text encoder。 用户原始描述称它是 BERT，但交接证据明确指出该身份没有在当前运行资产中独立核验。
 如果核验后发现当前已经是 BioClinical/ModernBERT/强 pathology-language encoder，那么 k1 的“创新性”和预期收益都显著下降，需要重新筛选。

条件 C：允许公平 downstream adaptation。 如果完全禁止重训 NPJ-C，那么 k1/k2 只能进行零样本兼容性 smoke test，不能形成可靠的 encoder 优劣结论。维度相同并不意味着 feature basis 相同。相反，若允许旧、新 encoder 在同一训练协议下各自重新训练 downstream NPJ-C，那么才能形成可信单因素比较。

本轮文献筛选也带来一个更一般、但很重要的结论：

“更现代 encoder”是一个值得实验的先验，不是性能定理。

scFoundation 在 TCGA survival 的 2026 研究尤其说明这一点：foundation embedding 确实可以带来非冗余预后信息，但 embedding-only 并没有自动超过原始基因表达，真正的大幅改善来自合理的特征组合。
 同理，BioClinical ModernBERT 在临床 NLP benchmark 上优于旧模型，并不能自动推出五个 TCGA 癌种 C-index 都提升。

因此，本轮可以锁定的是：

推荐候选 k1：BioClinical ModernBERT-base。
适用条件：原始 Text 可取；当前 Text encoder 经核验确实较弱/较旧；可重建全患者 Text feature space；允许对 old/new encoder 使用同一 downstream 训练协议。其最大优势是 768 维接口完全匹配 + clinical/biomedical domain adaptation + 权重/代码公开 + 不改变 WSI retrieval identity。

替代候选 k2：Clinical ModernBERT。
适用条件相同。它适合做一个较小、公开、同架构族的第二候选，检验 k1 的收益究竟来自 ModernBERT 架构还是更广泛的 BioClinical continue-pretraining；但从目前公开 benchmark 先验看，不应优先于 k1。
