## 1. Trigger：本次要解决的决策

我们在五癌多模态生存预测中已有“现有 encoder＋NPJ-C＋原型引导补偿及固定路由（S0-force）”系统。希望增加一个改动小、时间和计算成本可控的 encoder 辅助改进。请先判断优先替换 RNA、Text 或 WSI 哪个模态的 encoder，再给出至多两个最适合当前条件的候选 k1/k2。

已有 S0-force 的4/5胜率是五癌各自四场景均值严格超过均值填补和不补偿的探索性结果；它不是新 encoder 的证据，也不是纯原型检索的独立因果证明。新 encoder 尚未选定、尚无成绩。

该4/5包含由已见 test 启发、且在 valid 反对时仍强制启用的 LUAD 路由，存在 test 选择性泄漏，不能作为无偏验证或新 encoder 涨点的依据。

## 3. S_state：先读事实，别按论文名称猜当前实现

- 先验知识给出当前缓存形状、projector、检索与路由逻辑、源码快照、25条 None 原值和证据哈希。
- 当前 WSI 历史来源记录为 UNI2；RNA/Text 的精确提取模型、版本、原始输入可得性尚未核实。用户提到的原 NPJ 论文 BulkRNABERT/BERT/ViT 不能自动当作本次运行配置。
- 明确区分：①原始数据→基础特征提取器；②已有缓存→token encoder/projector；③模态间融合。每个建议注明层级，不得把新融合架构包装成低成本 encoder 替换。
- WSI 同时影响模型输入与检索 key；RNA/Text 同时影响本人输入、donor value、训练集均值。若换特征空间，必须指出一致性成本及归因混杂。
- 完整病例在 none 下不调用缺失补偿；none 的自然缺失病例仍走现有路由。不能因场景叫 none 就删除原型补偿。

## 4. How：仅进行证据检索与可行性筛选

1. 先列已读证据及不能访问的文件。私有 GitHub 未授权或附件读不到时明确说明，不假装读过；不要以摘要替代 SVG、源码和原始数值。
2. 先按当前接口、原始输入可得性、重提特征量、权重兼容性和所需训练比较 RNA/Text/WSI，给出有条件的优先顺序；不凭“旧模型过时”作决定。
3. 检索直接相关生物信息、TCGA 多组学/生存预测，以及最新相关会议和论文（如 CVPR/ICCV/ECCV 的 multimodal、missing modality、token fusion）。不强求论文一定属于这些会议；适配性优先于名气。
4. 可使用网页和 Consensus；若 Consensus 不可用，报告未使用。引用论文原文、作者代码、模型卡等原始来源，给出标题、年份、链接、代码/权重可用性与许可证证据；区分原论文结论和你的迁移推断。
5. 逐个执行 `P_i × S_state`：前提已满足／未满足／未核实。再按 `Q 约束＋任务适用域` 给出 Boundary，保留至多两个候选。若不足两个合格者，如实给一个或零个，不凑数。
6. 对每项说明：为何对当前数据和缺失任务可能有用、何时可能无效、替换的确切层级、输入输出、是否需原始数据、重提特征、训练、改 projector 或重建一致空间的 bank；这些仅为条件，不是执行许可。
7. 如新方案改变训练预算、特征空间或权重选择流程，单列“历史 Table 1 能否作严格单因素对照”。不能仅凭新旧 C-index 大小声称 encoder 因果有效；指出最小必要的公平性条件，交用户决定，不自行重训对照。
