# trimodalsurv：共享研究代码包

为各实验提供稳定的公共能力，避免为每个创新点复制数据、骨架和评测代码。

## 模块索引

| 路径                       | 作用与入口                                          |
| -------------------------- | --------------------------------------------------- |
| [data/](data/)             | 数据读取与批处理；主要实现为 `tcga_dataset.py`      |
| [models/](models/)         | NPJC、融合与公共补偿组件；骨架入口为 `npjc.py`      |
| [training/](training/)     | 共享训练流程、损失和运行工具；主流程为 `runtime.py` |
| [evaluation/](evaluation/) | 公共风险计算、评估辅助与缺失评测逻辑                |
| [config.py](config.py)     | 配置解析及运行参数、来源记录相关能力                |

## 代码边界

具体创新算子在各实验 `model.py`，通过组合接入，不在这里复制实验分支。输入填补发生在投影前还是编码后由该实验合同决定，不能只因都叫“补偿”就互换。

公共计算改动需检查受影响的[测试](../../tests/README.md)与实验测试。新增运行参数需追到真实消费者，并进入生效参数记录。

`__pycache__/` 是 Python 自动生成的缓存，不属于源码或实验结果。
