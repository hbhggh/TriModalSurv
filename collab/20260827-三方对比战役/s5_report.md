## 数据口径注记（判定前必读）

1. **12 case 剔除（用户裁决）**：BRCA 7（全 TCGA-OL 站点）、LUAD 5（全 TCGA-05 站点）。作者 UNI2-h 特征公开包固有缺失（tar 清单 0 命中；我方转换 531/531 无损）。三方同步剔除：BRCA 965→958、LUAD 432→427。BLCA/LGG/UCEC 无剔除。
2. **baseline test n 小于骨架 test n**（BRCA 347 vs 383、LUAD 167 vs 172、LGG 163 vs 166、UCEC 190 vs 198、BLCA 138=138）：两库官方 dataset CSV 对部分 case 无行（无 slide/genomics 记录），r2 契约期即已知。对被排除 test case 的事件率独立核验（BRCA 排除 36 例事件率 13.9% vs 保留 15.6%；LUAD 40.0% vs 37.7%；UCEC 25.0% vs 18.9%）：无系统性倾斜方向，不构成对任一方的利好。
3. **baseline 训练样本亦少于骨架**（官方 CSV 覆盖限制同源）：train 缺口 BLCA 0、BRCA **-31（383→352，-8.1%）**、LUAD -6（171→165）、LGG -4（166→162）、UCEC -9（197→188）。方向判读：LGG/UCEC 上 baseline 以更少训练样本胜出，故该处 baseline 优势为**保守估计（结论更硬）**；BLCA/BRCA 上骨架的领先则存在训练数据量混淆（骨架多 0~8.1% 训练样本），**幅度需打折看待**——但骨架同时多用两个模态（RNA+文本），模态差异本就是方法间差异的一部分（见结论 1 措辞）。
4. **RNA 缺失 11 案**（BLCA 2、BRCA 2、LUAD 4、UCEC 3）：GDC STAR-counts manifest 覆盖缺口，骨架按官方 mask 机制作 missing-modality 处理。
5. **NPJ 双口径**：A=作者口径（raw logits 累积风险，复现口径）；B=修正口径（sigmoid 后累积，数学正确口径）。ckpt 由 A 口径 valid 选出。
6. **ckpt 口径差异**：两 baseline 官方行为为末轮权重；骨架为 best-valid。不追平的原因：两库官方训练循环仅保存末轮权重，追平需改官方代码并全量重训 50 runs；本轮如实标注，若后续需要可在创新臂阶段补敏感性实验。
7. **qcut 泄漏防线**：两库官方在 split 前按传入 CSV 全体未删失患者做 qcut 分箱——存在 test 泄漏风险。本战役为此生成排除 test 的 trainval 训练副本顶替官方 CSV，并以含-test 硬失败校验兜底；50 份分箱断言（bins 仅源自 train∪valid，SHA256 指纹）全 PASS。
8. 批量化（任务 G `--batched_collate`）经实测为负优化（padding 浪费 + OOM），**未用于任何正式结果**；全部结果为官方 bs/gc 口径。

## 判定结论

1. **NPJ 骨架的优势不是全面的**：在统一患者名单与划分、统一评估协议下（各方法的模态集合与训练样本覆盖按其数据可得性，见注记 2/3——骨架用 WSI+RNA+文本，baseline 用 WSI+基因组），骨架仅在 BLCA/BRCA 领先；**LGG 上对两 baseline 0:5 全败（差距最大 −0.1415），UCEC 上对 PORPOISE 0:5 全败**，LUAD 三方打平。值得强调：LGG/UCEC 上 baseline 以更少的训练样本、更少的模态取胜，该反超是保守估计。原论文的全面优势叙事在本口径下不成立——这是"挤水分"论文的立论实证。
2. **A/B 双口径影响有限但非零**：|A−B|<0.02 者 18/25，≥0.03 者 3 格（最大 0.0438，LGG s123）；LGG 上 B 系统性高 +0.0166~+0.0438，且按 B 口径 LGG s123 骨架 0.8081 反超 MCAT 0.7911，vs MCAT 严格计数由 0:5 变 1:4；UCEC 上 B−A 双向摆动（−0.0254~+0.0369）。作者"评估端未过 sigmoid"缺陷不改变主要结论方向，但个别格点的胜负会翻转，论文中两口径都应呈现。
3. **PORPOISE（mutsig 配置）是被低估的强 baseline**：LGG/UCEC 上一致最强，且 5-seed 极差（0.0302/0.0284）仅为另两方的约 1/3——不仅均值高、方差也小。归因于 mutsig 基因组空间还是 PORPOISE 架构，需消融才能分离；注意同吃基因组的 MCAT 在 UCEC 反而三方最弱，"该癌种基因组信号强"的单因素解释不足。创新臂对照必须保留 PORPOISE。
4. 为创新臂（原型学习补偿缺失模态）留下的靶点：骨架在 LGG/UCEC 上的高 seed 方差（极差 0.10~0.13，为 PORPOISE 的 3~4 倍）与 missing-modality 场景（本轮 RNA 缺 11 案、WSI 缺 12 案剔除）的系统评测，均是下一阶段的直接切入点。
