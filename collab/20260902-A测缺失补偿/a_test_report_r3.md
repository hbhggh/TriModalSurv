**补充证据（gate 版四臂，附录表 `table_gate_4arms.md`，both_100 格点 vs M0-real）**：两模态全缺、仅剩 WSI 锚时，gate 版 M2（CAP-Recall）BLCA +0.018 / BRCA +0.060 / LUAD −0.0005（2:3）/ LGG +0.037 / UCEC +0.022；**均值盲补 M1 五癌全正**（+0.008 / +0.015 / +0.007 / **+0.048** / **+0.032**），且在 LGG/UCEC/LUAD 幅度高于 M2。因此 both_100 的增益主要归因于**"任何合理填充都优于作者的常量 bias token"**，学习式原型召回相对盲补的增量仅在 BRCA（+0.060 vs +0.015）与 BLCA（+0.018 vs +0.008）成立。基线提示：M0-real 在 both_100 上 LGG 极差 ~0.19、UCEC ~0.14，属高方差参照；BLCA M2 s213=0.4816 为另一崩坏 seed。E0/E1 的 both_100 补评测进行中。综合读法：**填充收益随信息缺口增大而增大——单模态缺失时（信息充足癌种）应关闭补偿，全缺时应开启填充；召回相对盲补的增量待 both_100 补评测与消融验证**。

## 四、机理证据（`probe/*.jsonl`、`notes.md`）

## 六、论文故事（r2 修订）
1. **主贡献：以 attention 融合替换伪门控**——作者 gate 的掩码链路为死代码、权重由 RNA 范数驱动（探针）；替换后 20:4:1 seed 提升、LGG +0.091（配对Δ中位）、UCEC +0.023。措辞："替换后一致更好"，不写"gate 有害"（贡献未分离，待消融）。
2. **CAP-Recall：条件性补偿**——收益取决于缺失模态在该癌种的可恢复信息量与信息缺口大小：UCEC 单模态缺失 15/15 全胜并把 seed 极差压至 1/7；全缺（both_100）时任何合理填充均优于常量 token、召回相对盲补的增量仅 BRCA/BLCA 成立；信息充足癌种的单模态缺失应关闭补偿。**自然引出选择性/自适应补偿作为下一篇的问题定义**。
3. 三句话进稿：①原骨架 gate 未按声称工作，缺失时以常量 token 照常融合；②我们以 attention 融合替换伪门控并用 CAP-Recall 从 WSI 锚与癌种原型召回缺失 token；③替换后 LGG 大幅、UCEC 一致提升；补偿在 UCEC 有效、全缺场景下填充有效而召回相对盲补的增量待验、信息充足癌种的单模态缺失应关闭——为选择性补偿提供实证。
